# .github

Organization-wide defaults for Dental-Practice-Mastery: issue templates used by any repo that does not define its own.

This folder is named `dot-github` locally; the repo on GitHub is named `.github`.

This repo is public because GitHub requires it: default files apply only from a public `.github` repo (GitHub docs, read November 23, 2026). Keep it to templates only. Nothing about the product, customers or internal decisions belongs here.
